# AES PROJECT — Utopia SNES Static Recomp

## Project Scope
This is a greenfield AES project for static recompilation of *Utopia: The Creation of a Nation* (SNES, USA). Follows the SimCity-SNES-Static-Recomp architecture.

## Sprint Layout

### sprint-01: Core skeleton and headless test

- T003: Implement PPU renderer stub
- T004: Write headless integration test (300 frames)
- T005: Integrate S-SMP AOT authority
- T006: Implement S-DSP core
- T007: Create SDL2 Linux frontend
- T008: Deploy script
